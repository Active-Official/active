# active-cli

The `active` command-line interface for the [Active](https://crates.io/crates/active) configuration and data language.

```sh
cargo install active-cli
active --version
```

Installing this crate provides the `active` binary.

## Status

Stable 1.0 implementation: eval, check, graph, impact, why, convert, import, generate, doc, lock, keygen, sign, verify, fmt, lint.
