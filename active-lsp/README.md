# active-lsp

Language server for the [Active](https://crates.io/crates/active) configuration and data language, speaking the Language Server Protocol over stdio.

```sh
cargo install active-lsp
```

Installing this crate provides the `active-lsp` binary.

## Status

Stable 1.0 implementation: hover, go-to-definition, references, rename, completions, diagnostics, inlay hints, code actions, semantic tokens.
