# C++ Binding SPEC (CHECKLIST 2.003, PROPOSAL section 2.1)

Status: smoke-proven. `smoke.cpp` exercises check with codes, eval with
JSON, T001 refusal, and secret redaction against the frozen ABI v1,
compiled with g++ 13 on Linux against a Linux-built staticlib
(cross-built on the host with `zig cc` as linker).

Ownership: RAII `unique_ptr` with custom deleters calling the matching
free function; borrowed diagnostic codes never freed; modules confined
to the calling thread per docs/FFI.md. The public header carries
`extern "C" { }` guards (generated by cbindgen `header`/`trailer`
settings, pinned by the header-drift test), so C++ translation units
include `active.h` with correct linkage.

Conformance path: the smoke asserts the same vectors the shared harness
runs (clean eval, T001 refusal, redacted secret). A harness `cpp` path
is future work pending a Linux-capable CI runner with g++; the proof
lives in the container transcript until then.
