*solid.txt*  SOLID language support for Neovim

Filetype detection, buffer defaults, syntax highlighting, and
`solid-ls` configuration for the SOLID configuration language.

1. Install                                          |solid-install|
2. Language server                                  |solid-lsp|

==============================================================================
1. INSTALL                                              *solid-install*

As a runtimepath plugin (no registry, no build). With vim-plug: >

  Plug 'RatioArtificiosa/solid-lang', {'rtp': 'editors/neovim'}

Manual: >

  set rtp+=~/src/solid-lang/editors/neovim

then `:helptags` the doc dir to read this file offline.

==============================================================================
2. LANGUAGE SERVER                                       *solid-lsp*

Install the server once (`cargo install solid-ls`), then with
nvim-lspconfig: >

  require('lspconfig').solid_ls.setup({
    cmd = { 'solid-ls' },
    filetypes = { 'solid' },
    root_markers = { '.git' },
  })

With Neovim 0.11+ built-in LSP (`vim.lsp.config`): >

  vim.lsp.config('solid_ls', {
    cmd = { 'solid-ls' },
    filetypes = { 'solid' },
    root_markers = { '.git' },
  })
  vim.lsp.enable('solid_ls')
